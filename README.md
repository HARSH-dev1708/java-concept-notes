# Java Concept Notes

A curated collection of Java concepts that I found important, confusing, or particularly interesting during my learning journey.

This repository is not intended to be a complete Java tutorial or a collection of syntax notes. Instead, it focuses on concepts that made me pause, think deeper, and truly understand how Java works internally.

The goal of this repository is to:

- Document concepts that were initially confusing
- Build deeper understanding of Java fundamentals
- Create structured technical notes for revision
- Track my learning journey publicly
- Improve both technical and explanatory skills

# Why I Made This Repository

While learning Java, I realized that many concepts are easy to memorize but difficult to deeply understand.

This repository is my attempt to:

- learn concepts properly instead of superficially
- document important insights

Most notes here are based on concepts I personally struggled with or found especially interesting.
